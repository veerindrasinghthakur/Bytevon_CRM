# Bytevon Screens — Organized by Module

Each original Stitch screen has been categorized into a module folder.

**Consistent naming inside every screen folder:**
- `screen.html` — the HTML export
- `screen.png` — the screenshot

> **Note:** The full organized package (HTML + PNG, ~32 MB) could not be written to the local Grok workspace due to a temporary filesystem restriction.  
> The original source zips are available in the project attachments:
> - `stitch_bytevon_ui_1.zip`
> - `bytevon_projects_screen.zip`

You can re-organize locally using the mapping below, or request a GitHub Release later.
