API Integration Refactoring

Modernize the legacy REST endpoints to support GraphQL queries and improve response times for the mobile client data synchronization pipeline.

description Description

The current REST API endpoints for user synchronization are experiencing significant latency during peak load times. This task involves refactoring the underlying data access layer and implementing a GraphQL interface to allow the mobile application to request only the necessary fields, reducing payload size by an estimated 40%.

Key Objectives:

  • Audit existing /api/v2/sync endpoints for N+1 query issues.
  • Design schema for User, Preference, and Device object types in GraphQL.
  • Implement Apollo Server middleware in the Node.js backend.
  • Ensure backward compatibility for legacy clients (v1.8 and older).
