Header Component Reference

This page serves as a standalone reference for the primary TopNavBar component within the Bytevon CRM ecosystem. It demonstrates the structural layout, active/inactive states for navigation links, integrated global search functionality, trailing action icons, and the authenticated user profile lockup designed for executive clarity.

navigation

Contextual Navigation

Primary navigation relies on clear typographic hierarchy. Active states are indicated by bold typography and a solid primary-colored bottom border to anchor the user's current context within the workspace.

search

Global Data Access

The persistent search bar accommodates long query strings, providing immediate access to Lead, Company, or Representative data without disrupting the current workflow view.

admin_panel_settings

Authority Lockup

Trailing utilities are grouped visually, separated from the user profile by a subtle divider. The profile lockup clearly displays the user's name and role, reinforcing the precise permissions model.
