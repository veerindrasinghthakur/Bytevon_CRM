## Super Admin Contract (authoritative — resolves prior open question)

```text
SUPER ADMIN AUTHORIZATION CONTRACT:
1. Bypasses ALL scope checks (SELF/TEAM/DEPARTMENT/LOCATION/ORGANIZATION/CUSTOM).
2. Bypasses ALL resource/action permission checks.
3. CANNOT bypass: authentication (valid JWT required), resource existence (404),
   business-rule validation (e.g. requester cannot approve own request),
   DB integrity constraints (FK, unique).
4. CAN: access any authorized resource, view/update all sensitive fields where
   business rules allow, assign/unassign any role except unassigning the last
   Super Admin holder.
5. CANNOT: delete system roles (is_system_role=True), rename system roles.
```

## Sensitive Field Contract (authoritative — resolves prior open question)

```text
SENSITIVE FIELD CONTRACT (from SensitiveField + RoleSensitiveFieldPermission models):
- can_read=true  → field INCLUDED in detail + list responses.
- can_read=false → field OMITTED (absent, not null) in detail + list + export.
- can_update=true  → create/update accepted if business rules allow.
- can_update=false → create/update REJECTED (400) if the field is provided.
- Nested objects follow the parent field's permission.
- Super Admin → implicit can_read=true, can_update=true on all sensitive fields.
- Filtering occurs at the serialization/response boundary (new core/serialization.py),
  not in DB queries.
```

### TASK-000 lifecycle (bounded readiness + cleanup, no stale processes)

```bash
cd 02_backend_code/
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 &
PID=$!
READY=0
for i in $(seq 1 30); do
  if curl -sf http://localhost:8000/health >/dev/null 2>&1; then READY=1; break; fi
  sleep 1
done
curl -f http://localhost:8000/health
STATUS=$?
kill $PID 2>/dev/null
wait $PID 2>/dev/null
(ss -ltn 2>/dev/null | grep -q ':8000 ' && echo "PORT STILL IN USE" && exit 1) || true
test $READY -eq 1 -a $STATUS -eq 0
```

Acceptance: HTTP 200 `{"status":"ok"}`, bounded ≤30s readiness, process terminated,
port released on BOTH success and failure. Failure → STOP.
